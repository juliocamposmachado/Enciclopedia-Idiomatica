## Sobre o projeto

A **Enciclopédia Idiomática da Inteligência Artificial** é uma iniciativa de pesquisa, sistematização e divulgação de conhecimentos sobre a relação entre a linguagem humana e os sistemas de inteligência artificial.

O projeto investiga como a estrutura linguística, a escolha de palavras, a organização sintática, o contexto semântico e a precisão das instruções influenciam a comunicação entre seres humanos e modelos de inteligência artificial.

A proposta é transformar conhecimentos técnicos e linguísticos em um ambiente de consulta, aprendizagem, experimentação e análise, reunindo conteúdo teórico e ferramentas interativas.

## Objetivos

- Investigar a influência da linguagem no processamento de informações por sistemas de IA.
- Compreender os mecanismos de tokenização e fragmentação textual.
- Estudar as particularidades do português brasileiro em modelos de linguagem.
- Comparar estruturas linguísticas entre diferentes idiomas.
- Desenvolver boas práticas de engenharia de prompts.
- Reduzir ambiguidades e inconsistências na comunicação com modelos de IA.
- Investigar a relação entre precisão linguística, consumo de tokens e custos computacionais.
- Promover o uso consciente, responsável e eficiente da inteligência artificial.
- Reunir referências técnicas, científicas e jurídicas relacionadas ao tema.

## Laboratórios e ferramentas interativas

O projeto contempla ferramentas para experimentação e análise.

### 1. Laboratório de tokenização

Permite inserir textos e observar características como:

- Quantidade de caracteres.
- Quantidade de palavras.
- Espaços e pontuação.
- Estimativa de tokens.
- Relação entre palavras e tokens.
- Comparação de textos.

As estimativas devem ser diferenciadas das contagens oficiais produzidas por tokenizadores específicos.

### 2. Comparador idiomático

Ambiente para comparar textos em diferentes idiomas, observando:

- Estrutura das frases.
- Extensão textual.
- Diferenças lexicais.
- Possíveis ambiguidades.
- Equivalência semântica.
- Estimativas de tokenização.

### 3. Laboratório de engenharia de prompts

Ferramenta para estruturar instruções com base em:

- Objetivo.
- Contexto.
- Papel funcional da IA.
- Tarefa.
- Restrições.
- Terminologia.
- Formato esperado.
- Critérios de validação.

O laboratório também propõe identificar ambiguidades, contradições e informações ausentes.

### 4. Simulador econômico

Calculadora para estudar o impacto financeiro do consumo de tokens, considerando:

- Tokens de entrada.
- Tokens de saída.
- Quantidade de requisições.
- Preços configuráveis.
- Projeções diárias e mensais.
- Comparação entre cenários.

Os preços são parâmetros configuráveis e não devem ser interpretados como valores oficiais atualizados sem consulta à fonte do fornecedor.

### 5. Laboratório de precisão semântica

Comparação de instruções para demonstrar como diferentes níveis de detalhamento podem modificar a interpretação e a qualidade esperada de uma resposta.

### 6. Índice de Eficiência Idiomática em Inteligência Artificial — IEIIA

Proposta metodológica experimental para avaliar dimensões como:

- Clareza.
- Precisão terminológica.
- Completude contextual.
- Coerência.
- Ambiguidade.
- Eficiência da instrução.
- Qualidade do resultado.

O IEIIA é uma proposta do projeto e não representa, neste estágio, uma métrica científica universalmente validada.

### 7. Biblioteca jurídica brasileira

Área destinada ao estudo das relações entre inteligência artificial, direitos fundamentais, proteção de dados, consumo, propriedade intelectual e responsabilidade civil.

Entre as referências legislativas estão:

- Constituição Federal de 1988.
- Lei Geral de Proteção de Dados — Lei nº 13.709/2018.
- Código de Defesa do Consumidor — Lei nº 8.078/1990.
- Marco Civil da Internet — Lei nº 12.965/2014.
- Código Civil — Lei nº 10.406/2002.
- Lei de Direitos Autorais — Lei nº 9.610/1998.
- Lei do Software — Lei nº 9.609/1998.
- Lei nº 14.129/2021 — Governo Digital.
- Lei nº 14.533/2023 — Política Nacional de Educação Digital.

A situação jurídica de cada norma ou proposta legislativa deve ser conferida em fontes oficiais.

## Fundamentação metodológica

A enciclopédia trabalha com a hipótese de que a qualidade da comunicação com sistemas de inteligência artificial depende de múltiplas dimensões linguísticas e operacionais.

Uma instrução pode ser gramaticalmente correta e, ainda assim, apresentar ambiguidades, ausência de contexto ou insuficiência de parâmetros.

Por isso, o projeto considera cinco dimensões fundamentais:

1. **Precisão lexical:** escolha adequada dos termos.
2. **Precisão sintática:** organização estrutural das instruções.
3. **Precisão semântica:** preservação do significado pretendido.
4. **Precisão pragmática:** adequação ao contexto e à finalidade.
5. **Precisão operacional:** definição clara dos resultados esperados e dos critérios de validação.

O projeto também investiga a relação entre essas dimensões e a eficiência computacional.

Não se presume que um idioma seja universalmente mais econômico em tokens que outro. O resultado depende do texto, do tokenizador e do modelo utilizado.

## Instalação e execução

### Pré-requisitos

- Node.js.
- npm.
- Git.

### Clonar o repositório

```bash
git clone https://github.com/juliocamposmachado/Enciclopedia-Idiomatica.git

cd Enciclopedia-Idiomatica
```

### Instalar dependências

```bash
npm install
```

### Executar em desenvolvimento

```bash
npm run dev
```

### Gerar versão de produção

```bash
npm run build
```

### Verificar a compilação

```bash
npm run
```

Consulte os scripts disponíveis no arquivo `package.json`. Os comandos acima pressupõem uma configuração compatível com Vite.
